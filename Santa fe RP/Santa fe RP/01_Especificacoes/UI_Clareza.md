# UI — Clareza (regra dos 2s)
- Ícone + número + no máx 3 palavras. Nunca frase na HUD.
- Sempre com unidade (R$, kg, km/h, m, min). Nunca número solto.
- Tempo conta pra baixo mm:ss. Cor: tema=você/ação, vermelho=perigo, verde=ganho, azul=aviso.
- Botão diz o que faz ("Segure F pra entregar"). Nome de gente, não de código.
